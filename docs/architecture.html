Factory Inventory Management — Architecture

A full-stack demo application with a Vue 3 single-page frontend, a Python FastAPI backend, and a JSON-file-backed in-memory data layer. No database. No persistence beyond server restart.

Data Flow

End-to-end path for a filtered dashboard request.

1
User selects filters in FilterBar.vue

Time Period · Warehouse · Category · Order Status. State lives in the useFilters composable, shared across views via module-level refs.

2
View reacts to filter change

A view component (e.g. Dashboard.vue) watches the composable's refs and calls api.getDashboardSummary(filters) in client/src/api.js.

3
API client builds the request

Filters become URL query params (skipping any with value 'all'). axios issues GET http://localhost:8001/api/dashboard/summary?....

4
FastAPI routes to an endpoint

Handler in server/main.py receives the query params as typed Optional[str] arguments.

5
In-memory filtering

apply_filters() and filter_by_month() reduce the in-memory lists loaded from server/data/*.json. Quarters (Q1-2025) expand to month ranges via QUARTER_MAP.

6
Pydantic validates the response

response_model on the route coerces the raw dict output into typed models before serialization. Validation failures surface as 500s during development.

7
Client stores raw data in refs

Derived values (totals, chart series, filtered lists) are computed() properties. Templates re-render on dependency change.

Key Conventions

Filter semantics

Value 'all' is a sentinel meaning "don't filter." It's stripped both in the client (before query-string build) and the server (before list filtering).

Reactivity pattern

Raw data lives in ref()s (allOrders, inventoryItems). Every derived value — filtered lists, totals, chart series — is a computed() property.

Inventory has no time axis

The month/Q* filter applies to orders, dashboard, reports — but not inventory. Inventory is a current-state snapshot.

Quarter expansion

Q1-2025 → ['2025-01', '2025-02', '2025-03'] via QUARTER_MAP. Month filters match by substring on order_date.
